# ChatGPT Web Client v1.4.20

适配新版 ChatGPT「聊天」和「工作」输入框，修复新会话打开队列后一直无法输入的问题。

- 支持新版 Work 输入框和对应的发送、停止按钮，继续兼容现有聊天页面。
- 网页输入框尚未加载时，队列面板自动重新检查；输入框就绪后自动恢复，无需关闭面板或刷新页面。
- 切换账号、标签页或页面时取消旧检查，保持每个会话的队列和草稿独立。
- 支持带模型参数的普通新会话首页；临时聊天仍不建立持久队列。

验证：真实已登录 ChatGPT 的聊天、工作模式各两条消息连续排队成功；原工作空间中两条待发送验收消息在重启后自动完成。115 项核心测试、发布文件检查、Go Agent 测试及相关桌面队列回归通过。

Windows 数据检查还确认了从打包宿主启动时的 AppData 目录重定向：它可能与桌面快捷方式读取不同的本地记录。两份数据分别保留，正常启动后原账号、标签页与任务均可读取。没有合并或删除账号登录资料。

详细验证记录：[新版输入框与首页队列](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.20/docs/validation/composer-home-2026-09-30.md)。
