# v1.4.23

修复网页长时间卡在加载界面，刷新无效、必须重启整个客户端才能恢复的问题。

- 加载超时、加载失败、网页进程崩溃或无响应时，自动重建当前标签页的网页实例。连续故障最多自动重试三次，手动“恢复页面”可重新尝试。
- 保留账号登录、标签页、原会话、队列和发送记录，不清除浏览器资料；其他会话的回复保持运行。
- 已可用的输入框不再被未完成的图片或嵌入资源挡住，状态检查不会被旧页面无限占用。
- 恢复任务跟随当前导航，已经恢复的页面、草稿或新打开的页面不会被旧回调重建。
- 本地诊断记录加载超时和恢复阶段，不记录会话内容、地址、账号标识或凭据。

验证采用真实 Electron 和独立离线账号，模拟固定网页实例永久无法加载、连续连接失败和未完成的网页资源。本次用户报告的原始卡死现场在排查时已通过重启恢复，无法据此断定当时具体是网页进程还是网络连接异常。此文档为发布准备记录，正式发布状态以 GitHub Release 页面为准。
