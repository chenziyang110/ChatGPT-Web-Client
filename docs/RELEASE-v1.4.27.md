# v1.4.27

支持在客户端内完成 Codex 网页授权并回到本机应用，减少切换外部浏览器。

- 登录或授权链接使用当前账号的独立环境，支持本机回调、成功页、服务器重定向及授权弹窗。
- 网页请求唤起 Codex 时显示“取消 / 打开 Codex”。确认后由系统打开已安装的 Codex；取消后可以再次操作，启动失败显示重试提示。
- 同一个授权标签页和其弹窗同时请求打开程序时，只处理一次；切换账号或标签页后，旧确认不会误打开程序。
- 取消或拒绝应用跳转不会触发网页恢复并反复请求一次性授权回调。运行中的会话队列、账号隔离及现有登录状态不受影响。
- 授权页面显示中性标题，回调参数和程序启动错误中的敏感内容不进入保存记录、诊断日志或确认框。

本机核对了 Windows Codex 协议注册与实际回跳路径。隔离的 Electron 回归使用真实本机回调服务测试完整跳转流程，程序启动调用使用测试替身；未重新授权用户真实账号。外部程序支持 Codex 标准成功页入口或明确声明的 Codex 回调，不执行网页提供的任意文件路径或命令。

提供 Windows、macOS 和 Linux 的 x64 / ARM64 安装包，Windows 与 Linux AppImage 支持软件内下载更新。更新保留账号、会话标签及队列记录。
