# v1.4.32

此候选未发布。完整桌面检查发现重试调度的边界竞争，修复后改由 v1.4.33 重新检查并发布。

修复新版 Your dot 页面已显示输入框，但会话队列一直停在“检查会话”“网页输入框正在加载”的问题，并更新运行时和构建依赖的安全补丁。

- 支持 Dot 新的两段会话地址，保留旧地址。会话绑定、消息发送和回复读取使用完整地址；不同会话和账号的队列、草稿与定时设置保持独立。
- 修复切换 Dot 会话后，已保存的“发送方式”变成“请选择”的问题。定时队列继续支持 10、20、30 分钟和自定义间隔。
- 兼容“无法加载此 ChatGPT 对话”卡片中的“再试一次”按钮。普通页面保留可手动重试的网页；正在执行队列的会话沿用原恢复机制和发送记录，避免重复提交消息。
- 更新 Electron 运行时及构建依赖，完整依赖审计为 0 项告警；保留账号隔离、本地数据、标签页、队列和主动暂停状态。

Windows、macOS、Linux 的 x64 / ARM64 共六个目标全部通过发布检查与产物核对后才发布为正式版。Windows NSIS 和 Linux AppImage 支持软件内更新；macOS 和 Linux tar.gz 使用对应安装包更新。

功能测试使用独立资料目录和离线网页，未向真实业务会话发送测试消息。跨架构打包不代表所有目标硬件均已完成原生验收。具体记录见 [Dot 新地址与队列设置验证](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.32/docs/validation/dot-compound-route-2026-11-02.md)。
