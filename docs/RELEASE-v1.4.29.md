# v1.4.29

修复回复连接中断后无法继续看到输出，以及软件内更新一直停在“准备更新”的问题。

- 当前回复出现断线提示、停止按钮仍在，且正文持续 6 秒没有变化时，自动重连同一会话，接回原任务输出。检测和等待期间保留已显示内容，有未发送草稿时暂缓重连。
- 输出重连独立于发送队列：普通观看、暂停队列和人工接管时也可恢复。不会重发消息、点击停止、解除暂停或因断线提前发送下一条。
- 首次重连遇到加载失败，或先出现空输入框后较晚报错时，继续对同一会话退避重试，最长间隔 30 秒。读回原轮次后才确认恢复；生成正式会话地址前保留原页面，新会话或新人工轮次不继承旧重连状态。
- 普通浏览中未触发输出重连的加载错误仍保留网页“重试”入口，不开启自动刷新循环。后台通知失败、短暂提示和继续增长的回复不会单独触发重连。
- 更新准备显示具体阶段，并限制在 10 秒内；超时后解除准备状态，保留已下载且校验通过的安装包，可再次安装。
- 准备期间选择强制安装，可升级正在等待的请求并跳过回复检查。仍须完成本地保存，连续点击只启动一次安装。
- `1.4.29-preview.1` 可更新至此正式版。账号、会话标签和队列记录保留，用户主动暂停或接管的状态不变；不上传账号凭据或浏览器资料。

自动重连通过重新加载页面恢复输出，尚未接管或验证 ChatGPT 私有输出接口；网络或服务不可用时仍有输出间隙，不保证无缝实时显示。

已在独立测试目录的 Windows Electron 和预览安装包内覆盖正文续增、草稿、暂停/接管、加载失败重试、发送凭据保留，以及更新准备超时、强制安装和去重。网络监控回归使用模拟响应元数据，并非真实 ChatGPT 接口抓包；没有在用户账号提交测试消息或执行覆盖安装。详见 [输出重连验证](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.29/docs/validation/reply-output-reconnection-2026-10-10.md) 与 [更新准备验证](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.29/docs/validation/update-preparation-2026-10-10.md)。

发布矩阵覆盖 Windows、macOS、Linux 的 x64 / ARM64，全部 CI 检查和产物核对成功后才发布。跨架构构建不代表所有目标硬件均已运行验收。Windows 与 Linux AppImage 支持软件内更新；其他格式使用官方下载入口。
