# ChatGPT Web Client v1.4.12

修复新会话加载卡住时界面无法切换账号，以及排队消息因网页操作失败而停在“需要处理”的问题。

- 点击“新对话”后立即可以切换账号或使用其他功能，无需等待 ChatGPT 网页加载完成。
- 网页持续空白加载时显示“恢复页面”；重试会重新打开原标签，已打开的其他标签和待发送消息保留。网页稍后自行加载成功时也会恢复显示。
- 会话面板的排队消息若在发送前因目标网页操作失败，会将本条记为失败并继续下一条；未发送的原消息不会被当成已发送或自动重发。
- 升级时自动清理旧版本因同类网页操作失败而留下的队列阻塞。人工接管、登录验证和未处理草稿仍需用户处理。
