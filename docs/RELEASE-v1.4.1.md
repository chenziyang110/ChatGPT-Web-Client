# ChatGPT Web Client v1.4.1

修复多个账号同时使用会话队列时，前一个账号的长时间回复占满执行名额、后一个账号一直显示“等待运行名额”的问题。

- 同一会话仍按顺序执行；等待网页空闲和已确认发送后的回复期间释放执行名额，其他账号或会话可以继续发送。
- 准备写入网页前重新取得名额并核对会话和草稿，避免等待期间人工输入或页面变化导致误发送。
- 后台回复约每两秒检查一次；正在查看的页面保持较快刷新。正在回复的网页继续保留，以便准确确认回复完成。
- 队列提示改为“等待发送”，避免把长时间回复误显示为占用运行名额。

Windows 安装版与 Linux AppImage 可在软件内“检查更新”后下载，并点击“安装并重启”。macOS 和 Linux tar.gz 仍使用本次 Release 的安装包手动更新。安装后未发送的队列保持暂停，请在核对会话后恢复。
