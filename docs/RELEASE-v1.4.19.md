# ChatGPT Web Client v1.4.19

改善会话队列的发送、长回复识别和重启恢复，并修复账号加载失败时误显示空账号界面的问题。

- 适配新版 ChatGPT 富文本输入框，正确处理 Markdown、链接和换行，支持复用内容一致的待发送草稿。
- 长回复导致历史消息从网页移出后，仍按已确认的消息标识跟踪当前轮次，避免回复已停止但队列一直等待。
- 会话回复报错、无法思考或中断后，结束当前轮次并继续下一条；仍在生成时继续等待。
- 页面暂时无法使用时自动恢复和重试，保留原队首消息；已经确认发送的消息不会重新提交。
- 重启后恢复对已发送回复的观察，避免旧网页历史或后续消息变化导致反复恢复失败。用户主动暂停、接管和网页草稿继续保留。
- 账号读取失败时显示明确的加载状态并自动重试，避免看起来像账号被删除；工作区界面崩溃后自动恢复，保留账号、标签页和队列。
- 新增有大小上限的本地启动、退出和异常诊断记录，不记录会话内容、账号标识或登录凭据，不上传日志。

验证：115 项核心测试、发布文件检查、桌面恢复与队列重启测试通过。实际客户端保留三个账号、八个原标签页和已有任务记录。

支持 Windows、macOS 和 Linux 的 x64／ARM64 版本。Windows 和 Linux AppImage 客户端可在软件内检查、下载并安装更新。
