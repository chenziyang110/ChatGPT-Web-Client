# v1.4.35

Dot 队列新增发送次数：写好一条消息后，可一次加入多条相同内容，再按当前发送规则依次执行。

- 快捷选择 ×1、×5、×10，也可输入自定义次数；×10 就是向当前 Dot 会话追加 10 条独立消息。
- 每条消息仍可单独编辑、调整顺序或移除，继续沿用定时发送或工作结束后发送。
- 不同账号、不同 Dot 会话分别保留本次选择的次数与草稿，切换页面或关闭面板后可继续编辑；已入队消息在重启后继续执行。
- 整批消息一次保存，失败重试不会重复添加，重启后不会集中发出全部逾期消息。
- 单次可加入 1–1000 条，可分批继续追加；队列总长度不受此限制。聊天和工作模式保留原有单条入队方式。

完整依赖审计为 0 项告警。Windows NSIS 和 Linux AppImage 支持软件内更新；macOS 和 Linux tar.gz 使用对应安装包更新。

验证使用独立资料与离线网页，未向真实业务会话发送测试消息。详情：[Dot 重复次数验证](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.35/docs/validation/dot-repeat-2026-11-04.md)。
