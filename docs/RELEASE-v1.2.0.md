# ChatGPT Web Client v1.2.0

降低多会话长时间打开时的内存占用，并新增系统全局老板键。

- 后台 ChatGPT 页面闲置一分钟后安全休眠，释放对应的 Chromium 渲染器和 GPU 表面；标签和会话地址保留，切回时自动恢复。
- 正在使用的页面、未发送草稿、生成中回复、Agent 占用页、登录/验证页和异常页不休眠，避免丢失状态。
- 会话通知轮询降为每 1.5 秒一次，活动检查只读取最新的用户和助手消息，不再每次扫描全部历史。
- 新增全局老板键：Windows / Linux 使用 `Ctrl+Shift+S`，macOS 使用 `⌘+Shift+S`；再次按下即恢复窗口并置于前台。Linux Wayland 桌面可能在首次使用时请求全局快捷键授权。
- 设置页显示固定老板键，并阻止其他快捷键与它冲突。

Windows 安装包尚未配置发布者签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 签名及公证。仅从本仓库下载，并核对 Release 附带的 SHA256SUMS.txt。安装前退出旧版；本地账号数据会保留。
