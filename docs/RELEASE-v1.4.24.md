# v1.4.24

本机开发版本，未单独发布 GitHub Release。累积正式发布见 [v1.4.25](RELEASE-v1.4.25.md)。

支持在当前账号内打开自定义登录或授权链接，同时包含 Dot 队列与网页恢复修复。

- 地址栏可直接输入或粘贴完整 HTTPS 链接，按 Enter 或点击箭头，在当前账号的新标签页打开。Esc 撤销编辑，输入法确认文字时不会误打开。
- 新标签页使用当前账号的登录状态，不替换原会话，也不添加或接管原队列任务。
- 支持授权提供方的 HTTPS 跳转和弹窗；初始链接明确提供本机 `redirect_uri` 时，仅允许对应地址、端口和路径的 HTTP 回调。
- 登录页保持可操作，不会因为其他会话正在排队而挡住账号选择。已就绪的授权页也不会因未加载完的嵌入资源被反复重建。
- 临时授权地址及标题不保存到应用数据库或本地诊断日志；重启后，未完成的授权标签页回到 ChatGPT 首页。账号浏览器资料继续在独立目录保存。
- 新增 `browser.openLink` 接口和 Node CLI `open-link` 命令。
- Your dot 的快速确认回复不再触发下一条排队消息：队列同时等待新回复和后台工作结束，已停止的失败工作仍按本轮结束处理。重启后继续等待原工作，不重复发送。
- 网页加载超时、失败、崩溃或无响应时，自动重建当前标签页，保留登录、原会话、队列和发送记录。其他标签页继续运行；连续故障达到自动恢复上限后仍可手动恢复。
- 已可用的网页不再被未完成的图片或嵌入资源误判为卡死，旧页面的恢复回调不会销毁已恢复页面或新草稿。
- 更新构建依赖，完整依赖审计通过。

验证包含核心与 Go 测试、真实 Electron 桌面回归，以及独立离线授权页、账号隔离、原生鼠标点击、弹窗、授权回调、队列保持与重启。离线授权测试不等同于所有第三方服务的实网验收。
