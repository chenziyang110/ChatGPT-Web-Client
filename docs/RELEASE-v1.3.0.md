# ChatGPT Web Client v1.3.0

修复内嵌 ChatGPT 的复制功能，并加入系统托盘、原生完成通知和隐藏窗口后的进一步内存优化。

- 修复 ChatGPT 网页中的复制按钮报错：仅允许可信 ChatGPT 主页面写入经过清理的剪贴板内容，其他页面与权限仍保持拒绝。
- 新增系统托盘：单击托盘图标可恢复并聚焦主窗口，菜单提供“显示主窗口”“隐藏到托盘”和“退出”。
- 回复完成后发送系统原生通知，通知包含账号和会话名称；点击后自动恢复窗口并打开对应账号的准确会话。
- 提高完成捕获准确性：回复内容需稳定六秒且没有忙碌标志才算完成，临时编辑器重绘不会丢失生成状态，打开仅有用户消息的历史会话也不会误报完成。
- 窗口隐藏或最小化十五秒后，当前安全页面也会休眠并释放 Chromium 渲染资源；重新显示窗口时自动恢复所选会话。
- 未发送草稿、生成中回复、Agent 占用页、登录或验证页等继续受到保护，不会被自动休眠。

Windows 安装包尚未配置发布者签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 签名及公证。仅从本仓库下载，并核对 Release 附带的 SHA256SUMS.txt。安装前退出旧版；本地账号数据会保留。
