# ChatGPT Web Client v1.4.3

修复 ChatGPT 回复显示错误卡片时，会话队列仍长时间停在“已发送，等待回复”的问题。

- 识别截图所示的“Unusual activity has been detected from your device. Try again later.”错误卡片，以及已有错误标记。确认本条消息已经发送到正确会话后，将本条任务结束为“失败”，不再等到超时，也不自动重发。
- 后续消息保留在该会话的队列中并暂停；请先查看 ChatGPT 页面，适合继续时再点“恢复队列”。其他会话和账号继续运行。
- 恢复后，即使上一条只有用户消息和错误卡片，也能继续发送下一条。历史错误卡片和在回复中引用的错误文字不会被当成当前错误。
