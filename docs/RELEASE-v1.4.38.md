# v1.4.38（Windows）

修复项目内普通聊天无法使用会话队列的问题。

- 支持项目内已有会话的 `/g/g-p-…/c/…` 地址，打开具体会话后即可排队。
- 完整保留项目路径，各项目、账号和普通会话分别排队，避免同名或相同末尾编号串队列。
- 同步修复回复完成识别、已发送记录恢复和会话加载失败检测，防止发出消息后继续卡在等待状态。
- 项目首页仍需先打开一个具体会话。自定义 GPT、临时与分享会话不在本次适配范围。

**本版仅提供 Windows x64 / ARM64 安装包**，Windows 用户可在软件内检查更新、下载、安装并重启。macOS / Linux 用户请继续使用 [v1.4.37](https://github.com/chenziyang110/ChatGPT-Web-Client/releases/tag/v1.4.37)，本版未提供对应安装包及更新清单。

验证使用独立临时资料与离线网页，覆盖项目会话连续发送、账号与项目隔离、暂停、重启和恢复读取防重发。构建与核心测试通过，依赖审计零告警。详见[验证记录](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.38/docs/validation/project-queues-2026-11-07.md)。
