# ChatGPT Web Client v1.4.15

修复新版 ChatGPT 网页中队列无法输入或发送的问题。本次先在三个已登录账号的真实网页检查元素并发送验收消息，再更新适配与回归测试。

- 同时支持旧版和新版输入框、发送／停止按钮、消息与完成状态，适配新会话的临时地址。
- 等待发送按钮真正可用；点击未生效且原草稿、原会话均未变化时自动补点，避免重复发送。
- 尚未发出的消息遇到页面异常时保留在队首，以 2 秒至 60 秒的退避间隔自动重试，不再跳过或消耗整条队列。
- 已发送消息保存本地发送记录；刷新、暂时断连、观察超时或重启后恢复等待原回复，不重新提交消息。
- 回复明确报错、无法思考、中断或停止后结束本轮，自动继续下一条；仍在生成时继续等待。
- 不覆盖网页已有草稿。需要登录或网页验证时保留任务，恢复后自动继续；用户主动暂停和接管仍然生效。

真实验收范围和限制见 [队列验收记录](validation/queue-live-2026-09-25.md)。
