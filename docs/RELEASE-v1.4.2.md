# ChatGPT Web Client v1.4.2

更新下载完成后，现在可选择“强制安装”。即使 ChatGPT 网页仍在回复或队列任务仍在等待，本地客户端也能在再次确认后保存数据、安装更新并重启。

- 普通“安装并重启”继续在有回复或任务进行时提示等待；“强制安装”需要单独确认。
- 强制重启会暂停未发送队列。已发送但尚未确认完成的任务标记为待核对，绝不会自动重发；重启后请先打开会话确认回复，再恢复队列。
- 关闭本地网页不保证 ChatGPT 服务端停止或继续生成。强制更新只中断客户端的本地跟踪；请以重新打开后的实际会话内容为准。

v1.4.1 客户端尚无强制安装按钮。如果当前长回复让它无法安装本版，可以正常退出 v1.4.1，手动下载并覆盖安装 v1.4.2。账号与排队消息保留，重启后按上述步骤核对会话。
