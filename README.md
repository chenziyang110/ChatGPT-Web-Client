# ChatGPT-Web-Client

A local AI workspace runtime based on Electron.

## Vision

Build a desktop AI environment that combines:

- ChatGPT Web Runtime
- Multi-account isolation
- Persistent sessions
- Agent Runtime
- AnythingCLI integration
- Browser automation

## Architecture

```
Electron
 |
 +-- Renderer UI
 +-- Account Manager
 +-- Session Manager
 +-- Agent Gateway
 +-- Storage Runtime
```

See `docs/` for product and architecture documents.
