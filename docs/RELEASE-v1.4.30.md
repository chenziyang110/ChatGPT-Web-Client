# v1.4.30

此候选未正式发布：Windows x64 的既有页面恢复回归未通过。后续修复版见 [v1.4.31](RELEASE-v1.4.31.md)。

Your dot 队列新增定时发送，可按设定间隔继续投递下一条消息，不再依赖 Dot 是否已结束后台工作。

- 在 Dot 会话队列的「发送方式」选择「定时发送」，可选每隔 10、20、30 分钟或自定义 1–1440 分钟，点击「保存」生效。
- 首条消息也等待所选间隔；后续从上一条确认送达时重新计时，面板显示下一条倒计时。Dot 的即时确认回复、后台思考和持续输出不会让队列提前发送或一直等待。
- 设置和到期时间保存在本机。重启或恢复后即使已过期，也只补发一条，再重新计时；不集中发送全部排队消息，不重复提交已确认送达的消息。
- 运行中启用或修改定时，尚未发送的消息会重新等待完整间隔。保存设置不会解除主动暂停或人工接管。
- 保留发送失败重试、人工草稿、登录、验证、真实停止按钮及不可用发送按钮的保护。已送达但输入框残留同一条原文时可清理并继续；人类编辑及重启后的草稿会保留。
- 定时模式的任务完成仅表示消息已送达，不代表 Dot 的远端工作结束。也可切回「工作结束后发送」；普通聊天、工作模式和前台 Agent 提问沿用原策略。

本地构建、177 项测试及发布清单测试通过；独立 Windows Electron 离线页面验证了实际设置操作、持续工作下按时投递、暂停与重启、截止时间、草稿和防重发。测试没有向真实业务会话发送消息，不保证覆盖未来网页改版或所有真实长时间后台场景。详见 [Dot 定时队列验证](https://github.com/chenziyang110/ChatGPT-Web-Client/blob/v1.4.30/docs/validation/dot-interval-queue-2026-10-19.md)。

Windows、macOS、Linux 的 x64 / ARM64 共六个目标全部完成发布检查和产物核对后，才发布为正式版。跨架构构建不代表所有目标硬件均已运行验收。Windows 与 Linux AppImage 支持软件内更新；账号、标签页、队列和主动暂停状态保留。
