# ChatGPT Web Client v1.4.0

按账号和会话独立排队，上一轮回复完成后自动发送下一条。新增软件内下载安装更新。

- 会话队列：简洁侧栏，可编辑、排序和移除待发送消息，暂停后续消息并保留当前回复；后台执行不切走正在查看的页面。
- 常用键盘操作：Enter 提交，Shift+Enter 换行；支持中文输入法选词保护，避免重复提交。
- 观看模式自动跟随最新回复，接管后停止跟随，方便翻阅历史。
- 改进真实 ChatGPT 富文本输入、发送确认和历史消息节点变化的识别，减少已发送消息的误报，不自动重发不确定的消息。
- Windows 和 Linux AppImage：软件内下载新版本、显示进度、校验安装包，再点击「安装并重启」完成覆盖升级。运行中的回复会阻止安装，账号、会话和排队消息保留。

## 升级

v1.3.1 及更早版本需要先从本次 Release 下载并覆盖安装一次 v1.4.0；后续版本即可使用软件内更新。请选择对应系统和 CPU 的安装包。重启后队列保持暂停，可手动恢复。

Windows 提供 x64 / ARM64 NSIS 安装包；macOS 提供 x64 / ARM64 DMG、ZIP；Linux 提供 x64 / ARM64 AppImage、tar.gz。macOS 当前使用 ad-hoc 签名，保留手动覆盖安装；Linux tar.gz 也使用手动更新。

Windows 尚无发布者签名，macOS 尚无 Developer ID 签名及公证。Release 提供 SHA256SUMS.txt；软件内下载另校验 SHA-512。所有下载均来自本仓库，不读取或上传 ChatGPT 登录信息。
