# ChatGPT Web Client v1.0.0

首个正式版：面向多账号使用与本机 Agent 协作的 ChatGPT 桌面工作空间。

- 多账号独立登录、会话恢复、专注模式和自定义快捷键。
- 任务中心、回复提醒、同会话串行与跨会话并行、暂停与人工接管。
- 本地 HTTP / CLI，以及 Windows Go Agent 工具，支持流式输出、断线续读和防重发。
- 新版自动检查、侧栏提示和手动检查；通过官方 Release 下载后安装。
- 带离线演示图片的使用说明；本地 API 默认关闭。

## 安装与升级

下载 `ChatGPT-Web-Client-1.0.0-win-x64.exe`，可使用 `SHA256SUMS.txt` 核对文件。Windows x64 安装包未配置代码签名，可能出现未知发布者提示。

已有开发版本请退出应用后手动安装，保留用户数据目录。本版开始支持未来版本通知；不会静默下载或强制重启。macOS / Linux 暂无本次正式安装包。

## 已知边界

需要自行登录 ChatGPT。登录、订阅、网络和验证码由对应服务决定；网页自动化依赖页面结构，变化后可能需要客户端更新。仅支持普通个人会话，暂不包含项目/GPT/临时会话与完整云端历史同步。

本项目独立开发，与 OpenAI 无隶属关系。
