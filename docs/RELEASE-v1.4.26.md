# v1.4.26

修复会话页面加载失败和回复连接中断时队列长时间等待的问题，自动恢复当前会话，减少手动刷新或重启。

- 网页显示“无法加载此 ChatGPT 对话”时，即使网页主文档已经加载完成，也会自动恢复原会话。持续失败会逐步延长重试间隔，最大三十秒，不会因三次失败永久停止恢复。
- 网页显示“连接已中断，正在等待完整回复”时，即使停止按钮仍在，正文持续六秒没有进展后也会自动刷新当前会话重新连接。回复继续更新时撤销重连，变化的思考计时不会掩盖断线状态。
- 恢复时保留账号登录状态、原标签页、会话地址和消息发送记录。已提交的消息不重复发送；重连后原回复仍在进行，就等它结束再发送队列下一条。
- 输入框有未发送草稿时保留可编辑的原页面和草稿，清空草稿后自动继续恢复。其他健康标签页和其他账号继续运行。
- 加载失败卡片消失、但会话仍停留在无输入框的加载占位页时，继续自动重试，避免队列失去最新状态。

验证包含核心和 Go 测试、真实 Electron 桌面回归、两轮 Windows 测试版试用，以及账号、标签页和发送记录保留检查。新增离线故障测试覆盖自动重连、恢复后继续生成、按顺序发送、草稿保护和账号隔离；实际网络持续不可用时仍需等待连接恢复。
