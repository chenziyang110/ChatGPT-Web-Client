# ChatGPT Web Client v1.3.1

修复新对话、Agent 人工接管恢复和待处理会话状态，并优化 Agent 长时间等待时的令牌消耗。

- “新对话”现在直接打开独立 ChatGPT 页面，不再创建页面导航任务，也不会等待其他会话的队列。
- Agent CLI 默认使用单一阻塞进程静默等待最终结果；实时增量与心跳改为按需启用，避免外部 Agent 反复轮询和输出状态而消耗额外令牌。
- 人工接管未发送的任务后，原阻塞等待会继续保持；处理完成后可直接点击“交还 Agent 并继续”，同一个任务会恢复执行，无需重发问题或创建新监控任务。
- 查看前台的准确会话时，会自动清除该会话的未读完成记录；不会误清同账号的其他会话或其他账号通知。
- 同步更新本地 Agent 提示词、CLI 帮助、接口与协作文档，使等待、接管、恢复规则保持一致。

Windows 安装包尚未配置发布者签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 签名及公证。仅从本仓库下载，并核对 Release 附带的 SHA256SUMS.txt。安装前退出旧版；本地账号数据会保留。
